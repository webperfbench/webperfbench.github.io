Makes sequential GET requests with a delay between each one.

  • ?r=100&d=100 - 100 requests, 100 ms apart (default r=10, d=100).
  • ?r=0&d=5000 - a request every 5 s, forever (the network never goes idle).
  • ?n=5 - shorthand for r=0&d=5000.
  • ?u=https://example.com/x - request URL (default same-origin blank.html). A random t param is added to avoid caching.
