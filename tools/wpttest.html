WPT Waterfall Indicator Test Page

This page exercises every indicator, icon, and tab in the WPT waterfall view in a single test run. Run it through any WPT instance and verify each row renders correctly side-by-side. Every request is labelled via a ?label= query param so you can identify it in the waterfall.

What each row represents

Row label (URL contains)IndicatorHow it's triggered
render-blocking Render Blocking Resource Sync <link rel=stylesheet> in <head>
404-favicon, 404-fetch, 404-img4xx+ responseRequest a non-existent path
3xx-fetch 3xx response Cross-origin URL that 301/302s (e.g. google.com → www.google.com)
cross-doc-img, cross-doc-fetchDoesn't Belong to Main DocSubresource loaded from inside an iframe (different documentURL)
insecure-img Insecure Request Plain http:// image. Note: modern browsers block this on HTTPS pages — the request usually won't even be made. Best verified on a separately-recorded HTTP test.
web-worker-* Worker dot + Worker tab Dedicated Worker calling importScripts() + fetch()
shared-worker-* Worker dot + Worker tab SharedWorker calling importScripts() + fetch()
sw-install SW dot + Worker tab fetch() from inside the SW's install handler
sw-message SW dot + Worker tab fetch() from the SW after postMessage from the page
sw-intercept-respond Worker tab w/ SW timings Main-thread fetch the SW intercepts and answers from cache
sw-intercept-passthrough Worker tab w/ SW timings Main-thread fetch the SW intercepts and forwards to network
